# ponza
Landing page di **Ponza Digitale** per presentare servizi, prezzi e contatti delle attività locali.

## Avvio locale
Apri `index.html` in un browser oppure usa un server statico, ad esempio:

```bash
python3 -m http.server 8080
```

Poi visita `http://localhost:8080`.

## Note implementative
- Pagina statica HTML/CSS/JS senza backend.
- Il form di contatto prepara un messaggio WhatsApp precompilato verso il numero indicato nel footer.
